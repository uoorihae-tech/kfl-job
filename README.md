# 한국외국어대학교 KFL대학원 취업정보 게시판 — 독립 사이트 만들기

이 폴더만 있으면 Claude 없이 돌아가는 사이트를 만들 수 있습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 본체 (게시판 화면) |
| `logo.png` | 대학원 로고 |
| `posts.json` | 자동 수집 공고 목록 (현재 165건) |

---

## 1단계. 사이트 올리기 (택 1)

### 방법 A — Netlify Drop (가장 쉬움, 5분)
1. https://app.netlify.com/drop 접속 → 무료 회원가입
2. 압축을 푼 **폴더 전체**를 화면에 끌어다 놓기
3. 바로 `https://임의이름.netlify.app` 주소가 생깁니다
4. Site configuration → Change site name 에서 `hufs-kfl-job` 처럼 바꾸면 `https://hufs-kfl-job.netlify.app` 이 됩니다
5. 파일을 고친 뒤에는 Deploys 탭에 폴더를 다시 끌어다 놓으면 갱신됩니다

### 방법 B — GitHub Pages (자동 업데이트까지 원할 때 추천)
1. https://github.com 가입 → 오른쪽 위 **+ → New repository**
2. 이름 예: `kfl-job`, **Public** 선택 → Create
3. **Add file → Upload files** 로 `index.html`, `logo.png`, `posts.json` 업로드 → Commit
4. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save
5. 1~2분 뒤 `https://내아이디.github.io/kfl-job/` 주소로 접속됩니다

## 2단계. 원우가 직접 공고 올리기 (구글 폼 + 시트, 로그인 불필요)

1. https://forms.google.com 에서 새 설문 만들기. **질문 제목을 아래와 똑같이** 적어 주세요 (사이트가 이 제목으로 열을 찾습니다).

| 질문 제목 | 유형 | 비고 |
|---|---|---|
| 학과 | 객관식 | 보기 4개: `외국어로서의 한국어교육학과` / `외국어로서의 한국어번역·커뮤니케이션학과` / `외국인을위한 한국문화·문학학과` / `공통 (전 학과)` |
| 구분 | 객관식 | 채용 / 인턴 / 공모·대회 / 교육·연수 / 기타 |
| 제목 | 단답형 | 필수 |
| 기관명 | 단답형 | |
| 마감일 | 날짜 | 상시면 비워두기 |
| 지역 | 단답형 | |
| 원문 링크 | 단답형 | 필수 |
| 내용 | 장문형 | |

2. 폼의 **응답 탭 → 스프레드시트에 연결** → 새 시트 만들기
3. (선택) 스팸 방지용 승인 기능: 시트 맨 오른쪽 빈 열 제목을 `승인` 으로 적어 두면, 그 칸에 **O** 를 적은 공고만 사이트에 보입니다. 이 열이 없으면 들어온 공고가 바로 보입니다.
4. 시트에서 **파일 → 공유 → 웹에 게시** → 대상: *설문지 응답 시트*, 형식: **쉼표로 구분된 값(.csv)** → 게시 → 나온 링크 복사
5. 폼 오른쪽 위 **보내기 → 링크 아이콘** → 응답자 링크 복사
6. `index.html` 을 메모장(또는 VS Code)으로 열어 아래 부분을 찾아 두 링크를 붙여 넣고 저장:

```js
const CONFIG = {
  FORM_URL: "여기에 구글 폼 응답자 링크",
  SHEET_CSV_URL: "여기에 웹에 게시한 CSV 링크",
};
```

7. 고친 `index.html` 을 1단계 방법대로 다시 올리면 끝.
   - 사이트에 **+ 공고 올리기** 버튼이 생기고 누르면 구글 폼이 열립니다.
   - 구글 '웹에 게시'는 약 5분 간격으로 갱신되어, 새 글은 몇 분 뒤 사이트에 나타납니다. 열어 둔 화면도 5분마다 자동 새로고침됩니다.

## 3단계. 자동 공고 업데이트 (posts.json 갱신)

사이트는 `posts.json` 을 읽어 자동 수집 공고를 보여줍니다. 이 파일을 갱신하는 방법:

- **방법 1 (추천, GitHub Pages 사용 시):** GitHub 저장소를 만든 뒤 Claude에게 "이 저장소에 posts.json 자동 업데이트 연결해줘"라고 저장소 주소를 알려 주세요. 지금 하루 2회 돌고 있는 자동 수집이 이 파일을 직접 갱신하도록 바꿀 수 있습니다.
- **방법 2 (수동):** Claude 게시판 버전에서 최신 `auto-posts.json` 을 받아 이름을 `posts.json` 으로 바꿔 다시 올립니다.

`posts.json` 형식 (직접 추가할 때 참고):

```json
{
  "updatedAt": "2026-11-13T03:30:00Z",
  "posts": [
    {"id": "고유값", "dept": "edu | trans | culture | all", "kind": "채용",
     "title": "공고 제목", "org": "기관명", "deadline": "2026-11-30 또는 빈칸",
     "location": "서울", "link": "https://원문주소", "content": "요약",
     "createdAt": "2026-11-13T03:30:00Z", "source": "auto"}
  ]
}
```

## 자주 묻는 질문
- **파일을 더블클릭하면 공고가 안 보여요** → 브라우저 보안 때문에 `posts.json` 을 못 읽는 것입니다. 1단계로 인터넷에 올리면 정상 작동합니다.
- **학과별 바로가기 링크** → 주소 뒤에 `#edu`, `#trans`, `#culture` 를 붙이면 해당 학과 탭이 바로 열립니다.
- **비용** → Netlify·GitHub Pages·구글 폼 모두 무료입니다.
